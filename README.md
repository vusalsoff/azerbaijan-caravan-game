# Azerbaijan Caravan Game (Demo MVP)

Azərbaycanın müxtəlif tarixi dövrlərini və mədəniyyətini əks etdirən 3D Açıq Xəritə karvan ticarəti oyunu.

## Qovluq Strukturu
- `Data/` — Şəhər mədəniyyət matrisi (`cities.json`) və random yol tapşırıqları (`quests.json`) *(Antigravity #1)*
- `Scripts/` — Daxili modul qoşma, `Merchant`, `Guard`, `Thief`, `TradeAndQuestManager` *(Antigravity #1)*
- `Scenes/` — `Story_Intro` (2D) və `World_Azerbaijan` (3D Açıq Xəritə) *(Antigravity #2)*
- `Art/` & `Prefabs/` — 3D personaj və şəhər modelləri, 2D Story illüstrasiyaları *(Antigravity #3)*
- `UI/` & `Audio/` — `HUDPanel`, `MarketPanel`, `QuestPopupPanel` və bölgə musiqiləri *(Antigravity #3)*

## Başlanğıc
Ətraflı məlumat üçün `LAYIHE_MEQZI.md` və `IS_BOLGUSU_VE_PROMPTLAR.md` fayllarına baxın.
